ArcFit Design System

Data-Dense & Functional — High information density, clear hierarchy, power-user focused

Design Philosophy

ArcFit prioritizes information density and functional clarity over decorative aesthetics. Every pixel serves a purpose. The design system enables power users to scan, compare, and act on fitness data efficiently.

Color Palette

Semantic color system with clear light/dark parity. Primary = Slate Blue (trust/focus), Secondary = Amber (energy/progress), Tertiary = Emerald (success/health).

Screen Patterns

Dashboard

  • Hero: Progress ring (100px) + 3 metric pills horizontal scroll
  • Quick Actions: 3-column responsive grid (48px min height)
  • Weekly Chart: Bar chart (200px height, 7 bars, today highlighted)
  • Progress Card: Inline metrics row (Volume, Sessions, Week, Time)

Workout Logging

  • Sticky Header: Title + Timer pill + Rest button
  • Exercise Cards: Expandable, inline steppers (sets/reps/weight)
  • Inline Rest Timer: Per-exercise rest tracking
  • Bottom Bar: Cancel / Finish (primary)

Nutrition

  • Date Picker: Compact inline with prev/next
  • Macro Rings: 3 donut charts horizontal (120px each)
  • Calorie Bar: Full-width linear progress
  • Meals: Collapsible sections, inline add food

Leaderboard

  • Podium: Top 3 with gradient backdrop
  • Categories: Horizontal scrollable chips with icons
  • List: Rank + Avatar + Name + Metric + Streak badge
  • Current User: Highlighted row with "YOU" badge

Accessibility

  • Touch Targets: Minimum 48×48px (Material 3)
  • Contrast: 4.5:1 (AA), 7:1 (AAA for key metrics)
  • Focus: 2px primary outline, 2px offset
  • Reduced Motion: Respects prefers-reduced-motion
  • Dynamic Type: Supports system font scaling up to 200%
  • Semantic Colors: Success/Warning/Error separate from brand
